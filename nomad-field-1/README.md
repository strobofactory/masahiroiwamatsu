# NOMAD FIELD — masahiroiwamatsu.com

Astro-based personal archive for Masahiro Iwamatsu.

## Stack
- Astro
- Static deployment (Vercel-ready)
- Astro Content Collections
- RSS
- Schema.org Person/WebSite metadata
- Mailchimp form placeholder

## Run
```bash
npm install
npm run dev
```

## Before launch
1. Replace `YOUR-MAILCHIMP-FORM-URL` in `src/pages/index.astro` with the Mailchimp embedded form action URL.
2. Add real books/works and profile details.
3. Add favicon/OG image.
4. Add sitemap integration if desired.
5. Point `masahiroiwamatsu.com` to Vercel after purchasing the domain.
